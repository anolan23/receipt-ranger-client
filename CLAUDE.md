# Receipt Ranger Client

Web client for Receipt Ranger, an app that turns receipts into spending insights. Users upload receipts, which are parsed into merchants, categories, and line items. The dashboard then shows spending overviews, category and merchant breakdowns, and monthly totals.

Stack: React, TypeScript, Vite, Tailwind, Radix UI primitives styled with the Receipt Ranger design system (receipt-ranger-design-system/, tokens in src/index.css), TanStack Table, Nivo charts.
