Every read state has an icon and a kind word: ⏳ In line, 👀 Reading…, ✓ All set, ✋ Take a peek (needs review) and ↻ Try again (failed). Failed reads use the soft `oops-*` pair, not alarm red.

Spending changes use `delta--win` (down, `win-*`) or `delta--rise` (up, warm amber `rise-*`) with a ▼ or ▲ and words. Increases are information, never a scolding: "$33.60 more on produce", not "Overspent".
